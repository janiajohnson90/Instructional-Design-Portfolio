# Instructional Design Portfolio

Hi! I'm Jania Johnson, an instructional designer with hands-on experience building e-learning in **Articulate Storyline 360** and **Articulate Rise 360**. This repository holds the source files, exported course builds, and design documentation for my portfolio projects.

Each course below was built for a fictitious company to demonstrate a specific set of instructional design and development skills—from clean microlearning in Rise to branching scenario design in Storyline to full software-simulation training.

## 📖 About Each Course

### 1. Welcome to Solstice Coffee Co. (Rise 360)
A new-hire onboarding course for a fictitious specialty coffee chain. Covers company values, team roles, food safety, and point-of-sale basics across five microlearning lessons. Built to demonstrate clean information design and a variety of Rise's interactive block types.

### 2. Doing the Right Thing: Workplace Conduct & Ethics (Storyline 360)
An annual compliance refresher for a fictitious financial services firm. The centerpiece is a full branching scenario — "The Client Dinner" — where learner choices lead to three distinct endings, tracked using Storyline variables.

### 3. Mastering MediChart (Storyline 360)
A software training course for a fictitious healthcare provider's new (fictitious) electronic health record system. Uses the view/try/test simulation pattern on custom-built UI mockups to train two core workflows: scheduling appointments and updating patient records.
